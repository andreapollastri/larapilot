Features

Everything a cycle needs, nothing it does not

Orbit keeps the essentials one keystroke away and hides the rest until you need it.

Cycle boards

Two-week cycles with a board, a list and a timeline. Drag an issue and everyone sees it move.

Keyboard first

Every action has a shortcut. Press ⌘K to jump to an issue, a project or a teammate.

Git aware

Branches and pull requests link themselves to issues and close them on merge.

Honest metrics

Cycle time, throughput and scope creep, computed from what actually shipped.

Triage assistant

New bugs arrive labelled, deduplicated and routed to the right project.

Secure by default

SSO, SCIM, audit log and data residency in the EU or the US.
