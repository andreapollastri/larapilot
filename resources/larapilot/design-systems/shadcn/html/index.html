shadcn/ui — Orbit

Static screens drawn with shadcn/ui new-york-v4 (Tailwind v4, oklch, neutral base) for Orbit, an issue tracker for product teams. One stylesheet, ../tokens.css, using shadcn's own variable names; no scripts, no web fonts. Read README.md and components.md first. The theme follows the OS; dashboard-dark.html forces .dark.
