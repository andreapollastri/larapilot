Laravel Starter Kit — Ledgerly

Static screens of the official Laravel 12/13 starter kits (React and Vue on shadcn/ui, Livewire on Flux) drawn for Ledgerly, a personal finance app. One stylesheet, ../tokens.css; no scripts, no web fonts. Read README.md and components.md before composing a new screen. The theme follows the OS; dashboard-dark.html forces dark.
