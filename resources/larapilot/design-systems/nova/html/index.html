Harbor CRM

Laravel Nova 5 — Larapilot design system

Static screens of a Nova 5 panel for Harbor CRM (contacts, companies, deals). Every screen links one stylesheet, ../tokens.css, and follows the OS theme; dashboard-dark.html forces dark. Classes are nv-*; the palette keeps Nova's own --colors-* variables. Mapping to Nova PHP classes: components.md.

Primary (sky; the light theme brands 400–600 two steps darker for AA) · Gray (slate) · Semantic

Dashboard — Main

Value, trend, partition, progress and table metrics on Nova's 12-column card grid.

Start here for any Nova\Dashboard or metric card.

Dashboard — Pipeline (dark)

Forced dark theme (html.dark) with the moon theme switcher, notification count, stalled-deals table.

Use to check a screen in Nova's dark theme.

Resource index — Contacts

Resource cards, search, Create button, select-all with 2 selected, action selector, lens / filter / delete menus, badges, booleans, row controls, Previous / Next.

Start from it for every Resource index.

Filter menu open

Two filters applied (solid funnel with count), Reset Filters, select / boolean / date filters, Per Page.

Use when a story adds Filters or Lenses.

Resource detail — Contact

Breadcrumbs, detail panels (PanelItem rows), Address panel, HasMany Deals table, empty HasMany Calls, success toast.

Start from it for detail pages and relationships.

Create form — Contact

Field rows label-left / input-right, required marks, one validation error, BelongsTo search, Select, Boolean, Date, read-only, Markdown, Image drop zone, footer buttons, error toast.

Start from it for create / update forms.

Action modal

ConfirmActionModal for a standalone Action with fields over the index: header, confirm text, fields, Cancel / Run.

Use for Actions with fields or destructive confirmations.

Notification center

Bell with unread count, slide-over with unread dots, action buttons, Mark Read / Delete.

Use when a story sends NovaNotification.

Empty and error states

"No Contact matched the given criteria." with an outline Create button; the index error dialog with Reload.

Use for zero-result searches, new resources, failed loads.

Log in (drawn credentials)

Nova's Welcome Back! card with drawn email / password fields, plus Forgot Password and Two-factor Confirmation cards.

Start from it for any auth page.

User Security

Nova 5 User Security page: Update Password (drawn fields, one error) and Two Factor Authentication with QR and recovery codes; user menu open.

Use for profile / security / settings tools.

Components

Every class of components.md in its variants and states: buttons, badges, inputs, dropdowns, table, metrics, modal, toasts, tabs.
