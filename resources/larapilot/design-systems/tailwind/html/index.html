Larapilot design system · tailwind

Tidewater, drawn in real Tailwind utilities

Every screen below is written with Tailwind v4 class names exactly as you would type them in Blade. The packaged tokens.css holds those utilities with Tailwind's own values, so the mockups render offline with no CDN and no build. Light and dark follow your OS; <html class="dark"> forces dark.
