Icons

AdminLTE 4 uses Bootstrap Icons (MIT). The mockups inline each glyph as SVG so no font file is needed. Copy a glyph's <svg class="bi" data-bi="…"> from this page's source; in the real app write <i class="nav-icon bi bi-truck"></i> with the bootstrap-icons package.

Sizing

An inlined glyph is 1em square on the text baseline, like the font: size with fs-*, colour with text-*. In the sidebar the same SVG takes nav-icon; in a small box small-box-icon; in an info box it sits inside info-box-icon.
