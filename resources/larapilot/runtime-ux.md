# Larapilot Runtime — UX & Web

The rules of design and of the public web, for **`larapilot-design`**, for **`larapilot-plan`** and **`larapilot-implement`** when a spec has UI, and for **`larapilot-ship`** on public sites.

This file is an index for people, and for a session that cannot run `php artisan larapilot:context`. A skill reads the parts that command lists for it — never every part by default. Without the command: find the heading the skill cites in the table below and read that part, whole, with the editor file-read tool (**Read protocol**, `.larapilot/shared-runtime.md`).

| Part | Headings |
| --- | --- |
| `.larapilot/runtime-ux-1.md` | UX & Frontend Design (technology preference, design systems, visual language, dark & light, mobile first, accessibility) |
| `.larapilot/runtime-ux-2.md` | Brand identity & assets, Frontend Engineering & Visual Impact, Mobile & Device Engineering |
| `.larapilot/runtime-ux-3.md` | SEO Structure & Discoverability, Copywriting & Content, Marketing & Growth |
