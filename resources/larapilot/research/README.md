# Research

Findings from discovery research — generated by Larapilot skills, not client uploads.

## Prior art

**Sebastian** writes `prior-art.md` at inception (when `settings.prior_art` is `YES`, default) after the consent question: the queries run, up to five existing open-source, packaged, or commercial candidates with license, stack, last release, what they cover and lack, adoption cost, and the verdict the user chose — `Build anyway`, `Adopt / fork`, `Integrate as dependency`, or `Not checked`. The PRD mirrors the verdict as `**Prior Art:**` under `## MVP Scope`.

## Reference products

Sebastian writes deepsearch reports under `reference-products/` when the user provides competitor or inspiration URLs during inception.

Each file summarizes: product URL, features, UX/design patterns, integrations, and ideas for this project.

## Legacy parity

When rewriting legacy software, **Sabrine** maintains parity matrices here (e.g. `legacy-parity.md`) — legacy content/feature → current implementation → new implementation → migration strategy.
